# 小丑军团 · Joker Legion

用扑克牌征兵，带着同一支军团走完十二波远征。战前从八张手牌中选一至五张，每手招一名士兵，再给一个战团下达牌型战令；开战后自动交锋，战后补给、买搭档、培养与融合老兵。

这是一个独立的 Vue 3、Vite 与 Canvas 2D 游戏 Demo。完整玩法、数值与角色设定见 [DESIGN.md](DESIGN.md)。

## 当前内容

- **十二波、双首领。** 第六波迎战无冕之王，胜利后继续远征；第十二波击败缀命皇后并守住城门才获胜。两位首领各有可见蓄力、范围标记与独立技能。标准和险境难度分别以 100、75 城门耐久开局。
- **六位可玩小丑。** 鬼手改点、双面复制、铃铛诱敌、夹层跨波留一张牌、替嗓同时向两队发令、活扣预系救命绳。每位每波一次专属戏法，并有一件起始搭档。
- **十二种征兵牌型。** 高牌至同花五条对应十二种征兵职业；四个战团负责近战、治疗、远射与法术。52 张牌绘各有身份、名字和造型，职业能力由实际征兵职业决定。
- **可追溯的计分连锁。** 选牌时展示基础筹码、计分牌点、道具来源、牌谱倍率、品质机会、战令及满编收益；出牌后依照真实顺序短促演示，可倍速或跳过，下一手立即可出。六件现有搭档区分计分、征募、出牌后与战斗触发，记录实际收益及未生效原因。
- **征募与战场兑现。** 高阶牌型聚焦最终分、品质揭晓、真实去向与受令士兵的实得变化。传说强化自身亮相；神话与棱彩在正式结算后引发约一秒的错峰致意，同波重复采用短版，候补明确保留在候补席。演出速度独立于战斗速度，支持暂停、立即显示、关闭及减少动态效果。
- **关键行动回顾。** 战团首次有效行动、护盾实际挡伤、止钟、皇后震荡打断和圣杯转伤害均读取真实事件；战报保留已有记录可支持的兑现摘要。多手战令与成员能力共同作用时，不把全部伤害归成某一手的额外伤害。
- **持续养兵。** 五个上阵兵位，正式士兵含本波阵亡者在守波后满血归营，身份、星级、经验、品质与已学能力跨波保留。满编时新传说进入候补，其他新兵转为集训经验。七档品质从常备到棱彩，品质变化后更换军装。
- **全部异职业融合。** 十二种征兵职业有 66 种不同职业的两两组合，一星即可花 5 金币融合。保留主兵身份、星级和品质，副兵永久基础生命、攻击、治疗全部合入，经验按合并后的历练重新计算，临时战令不复制。融合还继承副兵职业能力、已有能力与旧版战技，可继续融合其他职业；组合外观显示副职业装备。相同职业使用同星升星，免费升至最多三星。两传说升神话、两神话升棱彩的免费品质融合优先结算。
- **34 种商店物品。** 13 件独有搭档、15 件可叠层道具与 6 种自动消耗品。持有无槽位上限，购买后原货位标为已售出；可出售或花 2 金刷新。
- **战前构筑与战场观察。** 每波三手基础出牌、16 点军令和三次免费换牌，可加购出牌与改印牌组；备战调整三种阵型、拖动士兵位置、整编与融合。战斗支持暂停、倍速与角色戏法。手册显示真实来敌、牌谱研习与逐名战报。
- **前三波渐进引导。** 新局依次介绍高牌前排、对子牧师与列盾、当前角色戏法、鸣钟使与针对性布阵。按真实操作记录进度，可跳过一步或结束全部引导。高级功能逐步显示，旧存档不会重新锁住功能。
- **个人战报与本地历史。** 每名士兵记录伤害、有效治疗、生命承伤、护盾吸收和击杀；镜像单列，道具来源单列。简报显示总交战时长、城门损伤与修复、主要战令及剩余军令，等待玩家确认后进入补给。手册可查看本地历史并导出 JSON，最多保存 1000 波且不超过 3 MiB，无后端。旧档缺少的个人数据明确标为部分记录。
- **部署与补给体验。** 战场、名册和战报优先展示人物名，品质与职业作为次级信息。窄屏部署区避让实际控件和姓名区域；通知出现或消失不会推动军团。满血时修复补给禁用，并解释原因，仍可领取其他补给。
- **动作与声音。** 战斗事件驱动预备、出手、收势和命中。品质军装按头、躯干、双臂、双腿、披风和武器分部运动，坐骑四腿独立；身份牌绘、旧融合原画和普通敌军也有分部关节动作。融合增加副职业武器与徽记；最终首领有站姿、迈步、蓄力、挥剪、震荡、受击与收势共八种姿态的图集。射击与施法的命中反馈随投射物到达。三段配乐、音效开关、图鉴慢放与试听均已接入。
- **本地续玩。** 浏览器自动保存、同种子重试、每天北京时间零点刷新的「每日同局」与本机最佳成绩。
- **固定种子与构筑记录。** 开局可输入固定种子；本地战报保存每手牌型、分数、军令、征募与道具事件，以及鸣钟、突破、超时造成的城门损失和最终波次。三条正常操作的完整构筑路线可逐步重放。

## 开始试玩

在本仓库目录安装依赖并运行开发服务器。可使用 npm。

```bash
npm install
npm run dev
```

或使用 Bun。

```bash
bun install
bun run dev
```

打开终端给出的地址，默认是 [http://localhost:5173/](http://localhost:5173/)。若端口被占用，以终端实际地址为准。项目默认使用相对资源路径，可作为独立仓库部署。

## 构建与验证

```bash
npm test
npm run build
npm run preview
```

也可以使用 `bun run test`、`bun run build`。构建产物位于 `dist/`，可部署到静态网站托管。项目使用现有 Vue 3、Vite 与 Canvas 2D，战斗规则测试直接用 Node 测试运行器执行。

测试包含十二波推进与双首领技能、十二种牌型、六位小丑、66 种职业组合的双向融合、能力继承、品质融合、物品效果、存档验证和旧版迁移。浏览器中的动作观感与通关节奏还需要持续试玩反馈。

本轮体验优化的修改文件、统计口径和人工试玩项目见 [验收记录](docs/experience-optimization-2026-11-23.md)。生成离线版后，可用 Node 22+ 与本机 Chrome 复跑隔离浏览器验收，不会使用日常浏览器资料。

```bash
node scripts/check-experience-ui.mjs
```

可通过 `LEGION_CHROME_BINARY` 指定 Chrome 可执行文件，通过 `LEGION_TEST_URL` 指定开发入口；默认验收 `output/legion-demo.html`。

本轮计分与构筑的逐手实例、规则边界见 [计分循环验收记录](docs/scoring-loop-2026-11-23.md)。先生成三条完整合法路线及界面夹具，再运行计分界面验收。

```bash
node scripts/verify-builds.mjs
node scripts/check-scoring-ui.mjs
```

构筑验证从原始种子出发，只使用正常征募、商店、改印、研习、融合与战斗操作，并复放到相同的最终状态。界面验收另用隔离 Chrome 实际点击出牌、跳过、读档及完成战斗。

表现层的完整浏览器路线、五尺寸截图、状态一致性与边界说明见 [表现与战场兑现验收](docs/presentation-payoffs-2026-11-24.md)。其中种子 4 从鼠标新局一直用真实计时器交战到十二波胜利；演出开关、跳过与倍速的相同操作重放保持完整游戏快照与 RNG 一致。

```bash
node scripts/verify-presentation.mjs
LEGION_TEST_URL=http://127.0.0.1:5187/ node scripts/check-presentation-ui.mjs
```

运行后一项前，在另一终端用 `npm run dev -- --host 127.0.0.1 --port 5187` 启动开发入口。可用 `LEGION_UI_SCENARIOS=journey`、`sizes`、`quality` 或 `boss` 单独复测。生成证据位于 `output/`。

## 双击即可玩的离线版

单文件打包需要 Bun。已经构建时执行打包脚本，或用 `--build` 先构建再打包。

```bash
bun scripts/build-legion-demo.mjs --build
```

也可运行 `bun run offline`。生成的 `output/legion-demo.html` 可用桌面浏览器直接打开，无需服务器。脚本内联 JavaScript、样式、士兵与品质军装、敌军和最终首领动作、角色原画、战场及三段配乐。离线版使用系统中文字体。

若终端找不到 `bun`，可使用 Bun 的实际安装路径，例如 `~/.bun/bin/bun scripts/build-legion-demo.mjs --build`。`dist/` 与 `output/` 是生成内容，修改游戏后需重新构建和打包。

## 操作

| 操作 | 鼠标或键盘 |
| --- | --- |
| 选择或取消手牌 | 点击卡牌，或数字键 `1` 至 `8` |
| 战前征兵与下令 | 点击出牌，或 `Enter` |
| 加速或跳过计分演示 | 演示中点击 `1×` / `2×` 或「跳过演示」，不影响已结算收益 |
| 弃掉所选手牌 | 点击弃牌，或 `D` |
| 请求组牌提示 | 点击「提示」，或 `H`，再自行调整与出牌 |
| 调整站位 | 备战时拖到左侧布阵区，松手站定 |
| 训练或职业融合 | 将副兵拖到主兵身上停留，看到预览后松手；也可在工坊选择主副兵 |
| 同职业升星、品质融合 | 军团工坊；相同传说或神话品质也可直接拖合 |
| 暂停或继续战斗 | 点击战术暂停，或空格 |
| 切换战斗速度 | 点击 `1×` / `2×` |
| 查看角色图鉴 | 点击军团图鉴，或右键手牌直达该角色 |
| 动作慢放与试听 | 军团、敌军图鉴以及工坊中的动作预览 |
| 查看戏法、敌情、物品与战报 | 点角色头像、军议、已持有物品或随军手册 |
| 关闭说明与详情 | `Esc` |

出战后手牌收起，征兵、改印、整编与战令均在备战阶段完成。战斗暂停可观察战况、使用符合时机的角色戏法；暂停不会重新开放出牌。打开说明、详情、重开确认或切换到其他浏览器标签时，战斗会暂停。

前两波按战前最高单手牌分截取轻车或重车。第三波起，战前打过对子或更高牌型可自动打断首次钟击。可亮假旗误导普通敌军；首领有独立技能规则。

## 边界与素材

当前是可玩的原型，数值与长期平衡仍在迭代。推荐桌面浏览器；窄屏可以操作，但战场细节与同屏信息会减少。声音在首次点击后解锁，系统减少动态效果设置会降低动画。

进度只保存在当前浏览器的本地存储中。隐私模式、禁用或清理存储可能使续档不可用；页面会提示无法写入。离线文件与本地服务器属于不同来源，存档不互通。当前没有账号云同步或跨局永久养成。

旧版士兵及六种融合战技可继续读取；旧六波已结束的存档保留原结局，进行中的远征可接续十二波规则。素材提示词与来源记录见 [public/legion-pixel/PROMPTS.md](public/legion-pixel/PROMPTS.md)。52 张身份牌绘、按职业组合的装备、分部骨骼动作与部分角色的独立动作图集共同组成画面。
